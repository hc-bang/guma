# USER_GUIDE (사용자 가이드)

GUMA™를 효율적으로 사용하기 위한 기능 설명 및 활용 가이드입니다.

---

## 🔍 GUMA™란?

GUMA™는 **서버 없이 작동하는 개인용 브라우저 새 탭 대시보드**입니다.  
검색, 북마크, 문서 뷰어, 개발 도구, 자료실, 뉴스까지 한곳에서 관리할 수 있습니다.

---

## 🗺️ 화면 구성

| 영역 | 설명 |
|------|------|
| **상단 북마크 바** | 자주 방문하는 사이트 링크 및 폴더형 드롭다운 메뉴 |
| **메인 검색창** | 다중 검색 엔진 전환 및 빠른 검색 |
| **바로가기 그리드** | 자주 방문하는 사이트 아이콘 모음 |
| **실시간 이슈** | 하단 Google 뉴스 RSS 기반 실시간 카드 뉴스 |
| **좌측 사이드바** | 문서·도구·자료실·게임·환경설정 이동 |

---

## ✨ 주요 기능 사용법

### 1. 🔍 검색 엔진 활용

- 검색창 좌측 아이콘을 클릭하면 검색 엔진 선택 메뉴가 열립니다.
- **지원 엔진:** 네이버, 구글, 유튜브, GitHub, Bing 등
- 검색어 입력 후 `Enter` 키를 누르면 현재 선택된 엔진으로 검색됩니다.
- 마지막으로 선택한 엔진이 자동으로 기억됩니다.

### 2. ⭐ 바로가기 그리드 (Shortcuts)

- **추가:** 그리드 빈 공간의 `+` 버튼을 클릭하여 사이트 이름과 URL을 입력합니다.
- **삭제:** 아이콘을 **우클릭**하면 삭제 옵션이 나타납니다.
- **정렬 변경 / 초기화:** 환경설정 페이지에서 순서를 편집하거나 기본값으로 초기화할 수 있습니다.

### 3. 🔖 상단 북마크 바

- 링크를 클릭하면 해당 사이트로 즉시 이동합니다.
- 폴더 항목에 마우스를 올리면 중첩 드롭다운 메뉴가 열립니다.
- 환경설정에서 북마크 데이터를 GUI로 편집할 수 있습니다.

### 4. 🌙 다크 / 라이트 모드

- 우측 상단의 🌙/☀️ 아이콘을 클릭하여 테마를 전환합니다.
- 첫 방문 시 운영체제/브라우저의 시스템 설정에 따라 초기 테마가 자동 적용됩니다.
- 선택한 테마 설정은 브라우저에 저장되어 다음 방문 시에도 유지됩니다.

### 5. 📄 문서 뷰어

- 사이드바의 📄 **문서** 아이콘을 클릭하면 문서 목록 페이지로 이동합니다.
- 목록에서 항목을 선택하면 Markdown 파일이 렌더링되어 표시됩니다.
- 코드 블록은 구문 강조(Syntax Highlighting)가 자동 적용됩니다.

### 6. 🗂️ 자료실

- 사이드바의 🗂️ **자료실** 아이콘을 클릭합니다.
- 트리 구조로 파일/링크를 탐색하고, 항목 클릭 시 파일 다운로드 또는 링크로 이동합니다.

### 7. 🔧 개발 도구

사이드바의 🔧 **도구** 아이콘을 클릭하면 내장 개발 도구 목록이 표시됩니다.

| 도구 | 기능 |
|------|------|
| **JWT Debugger** | JWT 토큰 페이로드 디코드 및 검증 |
| **JSON Formatter** | JSON 문자열 정렬 및 들여쓰기 |
| **JSON ↔ Base64** | JSON 데이터를 Base64로 인코딩/디코딩 |
| **URL Encoder / Decoder** | URL 특수문자 인코딩/디코딩 |
| **키 생성** | UUID, 랜덤 시크릿 키 등 생성 |
| **ASCII Art Generator** | 텍스트를 ASCII 아트로 변환 |
| **인터넷 속도 측정** | 현재 네트워크 업/다운로드 속도 측정 |

### 8. 🎮 게임

- 사이드바의 🎮 **게임** 아이콘 클릭 시 외부 게임 월드 사이트로 이동합니다.
- 이동 전 로딩 화면이 잠시 표시됩니다.

### 9. 📰 실시간 이슈 (뉴스)

- 메인 하단에 Google 뉴스 RSS 기반의 실시간 이슈 카드가 자동으로 표시됩니다.
- 데이터는 **30분** 단위로 캐싱되어, 재방문 시 즉시 표시됩니다.
- 카드를 클릭하면 해당 뉴스 기사 원문으로 이동합니다.

---

## ⚙️ 환경설정 페이지

사이드바의 ⚙️ **환경설정** 아이콘을 클릭하면 모든 개인화 설정을 관리할 수 있습니다.

| 기능 | 설명 |
|------|------|
| **북마크 편집** | 상단 북마크 바 링크/폴더 구조를 GUI로 추가·수정·삭제 |
| **바로가기 편집** | 바로가기 그리드 순서를 드래그 없이 직접 편집 |
| **데이터 내보내기** | 현재 모든 설정을 JSON 파일로 저장 (백업) |
| **데이터 불러오기** | 저장한 JSON 파일을 불러와 설정 복원 |
| **초기화** | 모든 설정을 기본 상태로 리셋 |

---

## 💡 팁 & 주의사항

> [!TIP]
> 검색창에 포커스가 없어도 문자를 입력하면 자동으로 검색창에 입력됩니다.

> [!TIP]
> 검색창에서 `Enter`를 누르면 현재 선택된 검색 엔진으로 즉시 검색됩니다.

> [!WARNING]
> 모든 개인화 설정(북마크, 바로가기, 테마 등)은 **브라우저의 localStorage**에 저장됩니다.  
> 브라우저 데이터를 초기화하거나 다른 기기에서 사용하면 설정이 사라집니다.  
> 중요한 설정은 환경설정의 **데이터 내보내기** 기능으로 정기적으로 백업해두세요.

> [!NOTE]
> GUMA™는 정적 파일 기반이므로 서버 연동 없이 **로컬 브라우저에서만** 데이터가 저장됩니다.
