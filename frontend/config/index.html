사용자가 직접 검색 엔진을 구성할 수 있습니다. "적용"을 누르면 홈 화면에 즉시 반영됩니다.

우선순위: localStorage(guma_yt_channels) → 없으면 config/youtube-channels.json (기본값).
유튜브 다운로더의 최근 영상 목록에 표시될 관심 채널을 관리(추가/삭제)합니다.
URL은 https://www.youtube.com/... 또는 @핸들 형식을 지원합니다. "적용"을 누르면 즉시 저장됩니다.

외부(GitHub Pages 등)에서 접속할 때 유튜브 영상 분석 및 다운로드를 수행할 백엔드 서버(Cloudflare 터널)를 설정합니다.
로컬 환경(localhost, 127.0.0.1)으로 접속한 경우에는 자동으로 자기 자신을 연결하므로 별도 설정이 필요 없습니다.
